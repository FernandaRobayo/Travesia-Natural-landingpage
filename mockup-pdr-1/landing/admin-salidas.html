Salidas

Programar salida

Una salida es la ejecución programada de un tour con fecha, hora de inicio y hora de finalización estimada. El Administrador del tenant programa y cancela las salidas y asigna los vehículos; el inicio, la finalización, las novedades y la regularización los registra el Administrador del tenant o un usuario con el permiso Gestionar ejecución de salidas.

Alertas de salidas

Salidas sin cierre operativo

0 alertas

Al alcanzar la hora programada de inicio sin registro se genera una alerta; al superar la hora de finalización estimada la salida queda marcada como pendiente de regularización. Una salida nunca se cierra automáticamente por el paso del tiempo.

    Cancelar salida programada

    Cancelar salida

    La cancelación la realiza el Administrador del tenant por una causa no atribuible al cliente. Las reservas afectadas abren un episodio de reprogramación: 24 horas corridas para proponer una nueva salida con disponibilidad (límite del episodio de 96 horas); si no se propone o el cliente no acepta, se cancelan con devolución del 100 %. Toda propuesta pendiente hacia esta salida queda sin efecto.
