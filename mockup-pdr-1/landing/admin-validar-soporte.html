Acción disponible para el Administrador del tenant y para cualquier Colaborador operativo al que el Administrador haya asignado el permiso Validar comprobantes. Gerente, Contador y Analista no pueden recibir este permiso. El comprobante se revisa dentro de 24 horas corridas; pasado ese plazo queda marcado como revisión vencida, sin cancelar la reserva ni liberar el cupo.
