# Travesia Pages

Repositorio para publicar entregables de Travesia en GitHub Pages usando
subcarpetas independientes por proyecto o mockup.

## Estructura

- `mockup-pdr-1/`: primera publicacion copiada desde `C:\www\travesia\Landig Page`

## Convencion

Cada nuevo entregable debe vivir en su propia carpeta en la raiz del repo, por
ejemplo:

- `mockup-pdr-2/`
- `landing-comercial/`
- `demo-reservas/`

Esto permite publicar varias versiones o proyectos sin mezclar archivos entre si.
